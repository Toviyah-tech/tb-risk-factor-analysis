# Synthetic TB X-ray Risk Factor Analysis

This project analyzes a synthetic dataset of chest X-rays to identify patterns and distributions of Tuberculosis (TB).

## Dataset Source
The data is sourced from [Kaggle](https://www.kaggle.com/datasets/miadul/tuberculosis-x-ray-dataset-synthetic/data). It contains X-ray images categorized into **Normal** and **Tuberculosis** cases.

## Tools Used
- **Language:** R (Base R)
- **Environment:** R Markdown
- **Focus:** Data distribution, prevalence analysis, and metadata extraction.

## How to Run
1. Download the dataset from Kaggle.
2. Open `analysis.Rmd` in RStudio.
3. Update the `path` variable to point to your local data folder.
4. Click **Knit** to generate the report.
